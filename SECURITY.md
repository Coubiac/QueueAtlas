# Sécurité de QueueAtlas

QueueAtlas n'a pas encore de version publiée. Le code en développement reçoit des correctifs sur la branche principale ; une politique de support par versions sera publiée avant la première release.

Pour signaler une vulnérabilité, utilisez de préférence l'option **Report a vulnerability** de l'onglet Security du [dépôt GitHub](https://github.com/Coubiac/mailtrace/security). Si cette option n'est pas disponible, ouvrez une issue publique demandant un canal de contact privé, **sans** publier d'exploit, de données personnelles ni de secret.

Décrivez ensuite le composant, les versions ou commits concernés, les conditions de reproduction et l'impact dans le canal privé. Les journaux Postfix pouvant contenir des données sensibles, remplacez tout exemple réel par des valeurs synthétiques.

La politique de conception et les contrôles prévus sont décrits dans le [cadrage de sécurité](docs/phase-0-proposal.md#9-menaces-et-contrôles-dès-le-premier-serveur).
