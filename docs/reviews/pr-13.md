# Revue du chantier start_at:end

## Lot 66 : capture bornée et contrat

5 octobre 2026, base main `69dfe6bb056e4de326f2d77fc8aaf3433c2bf8b3`.
Coordinateur et auditeur indépendant : initial_end.go/tests et ADR-010 relus,
aucun blocage concret. Helper privé sans changement de Run, deps ou stockage.
EOF du descripteur, un ReadAt de 4096 octets maximum ; LF final exigé, CRLF accepté,
zéro vide canonique. Position inchangée ; erreurs/cancel/troncature sans ancre.
Frontière capturée conservée face aux appends, pas de scan non borné des lignes.

Trois tests TestCaptureInitialEnd* -count=1 Windows réussis par coordinateur et
auditeur. Suite locale go test ./..., go vet ./... et diff propres par coordinateur.
Premier échec du test Stat fermé : erreur invalid handle Windows, correction de
l'attente trop spécifique fs.ErrClosed ; le refus reste requis sur toute plateforme.
CI de publication à vérifier. Audit assisté par agents, sans certification externe.

Point d'intégration relevé pour lot 67 : bootstrap vide puis append doit consommer
les nouveaux octets depuis zéro, pas recapturer leur EOF après l'attente. ADR précisé.
Reprises/rotations ne doivent pas recevoir le mode initial end ; absence historique
et physique complète obligatoire avant d'ignorer volontairement un préfixe.
Limites : taille/contenu non atomiques, preuves bornées/Linux pour persistance,
pas de CLI/service/métriques livrés dans ce chantier.
